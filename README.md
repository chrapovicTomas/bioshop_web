Project is built using the latest technologies in the React ecosystem.

## Tech Stack

- **Frontend:** [Next.js](https://nextjs.org/) (React 19), [Tailwind CSS 4.0](https://tailwindcss.com/)
- **Database:** [Supabase](https://supabase.com/) & [Prisma ORM](https://www.prisma.io/)
- **Animations:** [Framer Motion](https://www.framer.com/motion/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Typing:** [TypeScript](https://www.typescriptlang.org/)
